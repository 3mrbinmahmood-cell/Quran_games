ألعاب تعليم مفردات القرآن والنحو والصرف

Quran Vocabulary, Nahw & Sarf Educational Games

مجموعة ألعاب تعليمية تعمل في المتصفح للمساعدة في دراسة مفردات القرآن الكريم، والنحو، والصرف.

A collection of browser-based educational games for studying Qur'anic vocabulary, Arabic grammar (Nahw), and morphology (Sarf).

المميزات | Features

ألعاب تعمل مباشرة في المتصفح.

واجهة عربية من اليمين إلى اليسار (RTL).

تمارين مفردات، مطابقة، استخراج، نحو، وصرف.

حفظ تقدم المستخدم محليًا في المتصفح.

ملفات مستخدمين باستخدام اسم مستخدم ورقم PIN بدون الحاجة إلى بريد إلكتروني.

شريط تقدم للجولة أو الاختبار الحالي.

شريط تقدم للمجموعة الكاملة من الأسئلة.

تتبع الأسئلة التي أُنجزت.

دعم مراجعة الإجابات الضعيفة أو الخاطئة في الألعاب التي توفر ذلك.

Designed to cycle through the full question set rather than repeatedly selecting only a small portion of it.

تسجيل المستخدم وحفظ التقدم | User Profiles & Progress

لا يحتاج المستخدم إلى بريد إلكتروني. يمكن إنشاء ملف محلي باسم مستخدم ورقم PIN.

يتم حفظ التقدم باستخدام تخزين المتصفح المحلي (localStorage). لذلك فإن الحساب ليس حسابًا مركزيًا على الإنترنت، ولا تنتقل البيانات تلقائيًا إلى جهاز أو متصفح آخر.

The username/PIN system is a local profile system. Progress is stored in the browser's local storage. It is not an online authentication service, so progress does not automatically synchronize between devices or browsers.

استخدم ميزة تصدير/استيراد النسخة الاحتياطية، إن كانت متاحة في الإصدار المستخدم، لنقل أو حفظ بيانات التقدم.

التشغيل | Running the Games

يمكن تشغيل الألعاب بفتح ملفات HTML مباشرة، أو استضافتها على GitHub Pages أو أي خادم ويب ثابت.

The games can be opened as HTML files or hosted as a static website, including through GitHub Pages.
